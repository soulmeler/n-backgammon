# BlitzGammon

BlitzGammon — веб-платформа для быстрых нард на `Next.js + React + Tailwind`, с фокусом на высокий темп партии, чистый интерфейс и AI-сопровождение после матча.

## Концепция

**BlitzGammon** создан как продукт, который делает ставку на:

- короткие, динамичные матчи;
- минималистичный понятный UX без перегруза;
- живую доску, визуально близкую к реальной настольной игре;
- выбор сложности AI перед стартом;
- post-game coaching сразу после завершения партии.

## Что реализовано

### 1) Навигация (маленький navbar сверху)

- `Play vs AI`
- `Lobby` (demo-вкладка, как вы просили)
- `History` (история всех матчей)
- `Rating` (рейтинг по стране и регионам Казахстана)

### 2) Игра против AI (полностью рабочая)

- Настоящая игровая доска с двумя половинами, баром и зоной выноса;
- Полная логика хода в коротких нардах (backgammon-style):
  - бросок кубиков;
  - обязательность максимально полного использования кубиков;
  - правило большего кубика, если возможен ход только одним;
  - удары (hit), бар, возврат с бара;
  - bear off (вынос шашек) по правилам;
- Подсказка доступных ходов через интерактивные выделения;
- Итоговая плашка результата после окончания матча;
- Таймер длительности партии.

### 3) AI и Groq

- Выбор сложности перед матчем: `Easy`, `Medium`, `Hard`;
- На `Hard` подключается запрос в Groq API;
- В UI отражено: **Llama 3.5 via Groq API**;
- При отсутствии API-ключа есть fallback на локальную эвристику (матч не ломается).

### 4) Тема

- Переключатель `Light / Dark`;
- Состояние темы сохраняется в `localStorage`.

### 5) История матчей

- Каждый матч записывается локально:
  - дата/время;
  - победа/поражение;
  - сложность;
  - длительность.

### 6) Рейтинг Казахстана

- Таблица рейтинга по стране/регионам (демо-данные для MVP).

## Стек

- `Next.js 14` (App Router)
- `React 18`
- `TypeScript`
- `Tailwind CSS`
- Серверный API-route для Groq (`/api/groq-move`)

## Структура проекта

```txt
app/
  api/groq-move/route.ts      # Серверный прокси для выбора хода через Groq
  globals.css                 # Цветовая система и базовые стили
  layout.tsx
  page.tsx

components/
  BackgammonBoard.tsx         # Реалистичная интерактивная доска
  BlitzGammonApp.tsx          # Главный экран, вкладки, логика UX

lib/
  ai.ts                       # Клиентский вызов Groq route
  backgammon.ts               # Движок игры (правила, ходы, AI-эвристика)
```

## Быстрый старт

```bash
npm install
npm run dev
```

Открыть: `http://localhost:3000`

## Переменные окружения

Создайте `.env.local`:

```bash
GROQ_API_KEY=your_groq_api_key_here
# опционально:
GROQ_MODEL=llama-3.3-70b-versatile
```

Если `GROQ_API_KEY` не задан, режим `Hard` будет работать на встроенной логике выбора хода (fallback).

## Примечания по UX/дизайну

- Сайт выполнен в двух главных цветовых тонах с высокой читаемостью;
- Верхний бар компактный;
- Игра — центральный элемент, без визуального шума;
- Интерфейс сделан с упором на продуктовый стиль, а не шаблонный “вайбкод”.
